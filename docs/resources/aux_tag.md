# checkmk_aux_tag (Resource)

Manages a CheckMK auxiliary tag configuration. Auxiliary tags do not require activation.

Note: Built-in aux tags (ip-v4, ip-v6, snmp, tcp, checkmk-agent, ping) cannot be deleted or modified.

## Example Usage

```terraform
# Basic auxiliary tag
resource "checkmk_aux_tag" "monitored_by_agent" {
  id    = "monitored_by_agent"
  title = "Monitored by Agent"
  topic = "Monitoring"
  help  = "Host is monitored via CheckMK agent"
}
```
