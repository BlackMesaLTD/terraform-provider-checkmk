# checkmk_user (Resource)

Manages a CheckMK user. Users can authenticate via password or automation secret. Does not require activation.

## Example Usage

```terraform
# Basic user with password authentication
resource "checkmk_user" "operator" {
  username = "jsmith"
  fullname = "John Smith"
  email    = "jsmith@example.com"

  auth_type = "password"
  password  = "SecurePassword123!"
}
```

## Schema

### Required

- `fullname` (String) Full name of the user.
- `username` (String) Unique username for the user. Cannot be changed after creation.

### Optional

- `auth_type` (String) Authentication type: 'password' or 'automation'. Default is 'password'.
- `automation_secret` (String, Sensitive) Automation secret for the user. Required if auth_type is 'automation'. Sensitive.
- `contact_groups` (List of String) List of contact group names the user belongs to.
- `disable_login` (Boolean) If true, the user cannot log in to the GUI.
- `email` (String) Email address of the user.
- `enforce_password_change` (Boolean) If true, user must change password on next login. Only applies to password auth.
- `password` (String, Sensitive) Password for the user. Required if auth_type is 'password'. Sensitive.
- `roles` (List of String) List of roles assigned to the user. Common roles: 'admin', 'user', 'guest'.
- `strict_resource_locking` (Boolean) Override provider-level strict_resource_locking for this resource. Controls ETag validation for resource operations. If not set, uses provider configuration.

### Read-Only

- `id` (String) The unique identifier for the user (same as username).
