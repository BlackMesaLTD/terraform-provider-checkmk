# checkmk_service_group (Resource)

Manages a CheckMK service group. Service groups provide logical grouping of services for rules and reporting. Does not require activation.

## Example Usage

```terraform
# Basic service group
resource "checkmk_service_group" "http_services" {
  name  = "http_services"
  alias = "HTTP/HTTPS Services"
}
```
