# checkmk_host_group (Resource)

Manages a CheckMK host group. Host groups provide logical grouping of hosts independent of folder hierarchy. Does not require activation.

## Example Usage

```terraform
# Basic host group
resource "checkmk_host_group" "webservers" {
  name  = "webservers"
  alias = "Web Servers"
}
```
